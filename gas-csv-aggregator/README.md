# CSV 集計ツール（Google Apps Script 版）

Google ドライブのフォルダに入れた売上・注文の CSV を、メニュー 1 回で **「年月 × 商品」の集計表** にする Google Apps Script です。Shift_JIS と UTF-8 のファイルが混ざっていても、列の順番がファイルごとに違っていても読めます。期間が重なる CSV を入れても、同じ行を二重に数えません（例外は「9. 制限事項」）。

> 自主制作物です。実際の業務で使われたシステムではありません。
> **Google の環境では、自己テスト（19 項目）だけを確かめました（2026-10-26、すべて合格）。本番のメニューからの実行はまだ確かめていません。** そのほかの動きは Node.js のテスト（GAS のサービスを偽物に置き換えたもの）で確かめています（「9. 制限事項と動作確認の状況」）。

集計のルールは [Excel VBA 版](../excel-csv-aggregator/) と同じです。VBA 版の参照実装 `lib.js` をそのままコピーして使い、同じテストケース（入力 CSV と手で計算した期待値）で確かめています。

## 1. 何をするツールか
1. 「設定」シートに貼ったドライブのフォルダから、`.csv` をすべて読む（元のファイルは読むだけで、書き換えない）
2. 文字コード（Shift_JIS / UTF-8 / UTF-8 の BOM あり）を自動で判定する
3. 見出し名で「注文日・商品名・数量・金額・注文番号」の列を探し、決まった形の明細にそろえる
4. 複数の CSV に同じ行があれば 1 回だけ数える
5. 同じスプレッドシートに「集計」「月別合計」「明細」「取り込み結果」の 4 シートを作り直す
6. フォルダにあって読まなかったファイル（`.csv` 以外など）とサブフォルダの名前を、画面と「取り込み結果」に出す

## 2. 解決する課題
- 管理画面からダウンロードした CSV を毎回開き、1 枚のシートに貼り付け、列を消して並べ替え、ピボットテーブルで集計している
- 期間が重なる CSV を落とすと、同じ注文が二重に入る。気づかないまま売上が多く見える
- スプレッドシートで CSV を読み込むと、「0012」のような商品コードが 12 になる、Shift_JIS のファイルが文字化けする
- Excel がない、または Excel のライセンスが切れていて VBA 版を使えない

## 3. 主な機能
| 機能 | 内容 |
|---|---|
| フォルダ内の CSV をまとめて読む | `.csv` だけを、ファイル名の文字コード順に読む（大文字が小文字より先、`10` が `9` より先。ドライブの並びとは違う）。`~$` で始まる一時ファイルは読まない。サブフォルダの中も読まない |
| 読まなかったものを知らせる | `.csv` 以外のファイル、名前の最後に空白が付いたファイル、Google スプレッドシートに変換されたファイル、サブフォルダの名前を、成功のメッセージと「取り込み結果」の表の下に出す（エラーにはしない） |
| 文字コードの自動判定 | 先頭の BOM → UTF-8 として正しいか → Shift_JIS の順で判定。設定で固定もできる |
| 文字化けを止める | 文字コードの変換で読めない文字があったファイルは、行番号つきのエラーにする（化けたまま集計しない） |
| 列を見出し名で探す | 列の順番違い・余分な列があってもよい。見出し名は「設定」シートで変えられる |
| 重複の削除 | 同じ行が複数の CSV にあるときは、ファイルごとの件数のうち最大の数だけ残す。1 つの CSV の中で同じ内容の行が 2 つあっても消さない。注文番号の列がない CSV では注意が必要（「9. 制限事項」） |
| 集計 | 年月 × 商品（数量・金額）と、年月ごとの合計 |
| 入力チェック | 日付・数量・金額が読めない行、必要な列がない CSV、閉じていない引用符（`"`）、余分な引用符で複数の行が 1 つの値に入ったように見える箇所、UTF-16 のファイル、Google 形式のファイルがあれば、集計を作らずにファイル名と行番号の一覧を「エラー」シートに出す |
| 他のシートを壊さない | 書くのは出力用の 5 シート（集計・月別合計・明細・取り込み結果・エラー）だけ。同じ名前で 1 行目の見出しが違うシート（依頼者が作ったもの）があれば、何も書かずに止まる |
| 途中で止まっても前回の結果を残す | 「（作成中）」の名前で全部書いてから入れ替える |

## 4. 使用技術
- Google Apps Script（V8）、Google スプレッドシート、Google ドライブ（読み取りだけ）
- テスト: Node.js 標準のテストランナー（`node:test`）。外部ライブラリなし
- CI: GitHub Actions（テスト、gitleaks による秘密情報スキャン）

### ファイル
| ファイル | 中身 |
|---|---|
| `src/lib.js` | 集計のルール。`excel-csv-aggregator/src/lib.js` のコピー。**手で編集しない**（`npm run sync-lib` で作る。テストで一致を確かめている） |
| `src/gas-lib.js` | GAS 版だけの純粋関数（設定の読み方、フォルダの ID の取り出し、読まなかったファイルの一覧、シートに書く値など）。`lib.js` はコピーなので、ここに足す |
| `src/main.js` | GAS の処理（メニュー、ドライブの読み込み、シートへの書き込み） |

| `src/selftest.js` | 自己テスト（開発用。**納品物には入れない**）。テスト用のスプレッドシートで、共通テストケースを Google の上で流して結果をシートに書く（「9. 自己テスト」） |

## 5. セットアップ方法
### かんたんな方法（コピー＆貼り付け）
1. 新しい Google スプレッドシートを作る（このツール専用にする）。
2. 「拡張機能」→「Apps Script」を開く。
3. 最初からある `コード.gs` の名前を `main` に変え、中身を `src/main.js` に置き換える。「＋」→「スクリプト」で `lib` と `gas-lib` を足し、`src/lib.js`・`src/gas-lib.js` の中身をそれぞれ貼り付ける。エディターではファイル名に `.gs` が付き、`main.gs`・`lib.gs`・`gas-lib.gs` になりますが、それでかまいません（ファイルの並び順も問いません）。最後に保存する。
   - **貼る前に、エディタの中身を空にする**（右側をクリック → Ctrl+A → Delete）。最初からある `function myFunction() {` や、元の `appsscript.json` の中身が残ると、メニューが出ない・保存できないなどで動きません（2026-10-25 に実際に起きた）。貼ったあと、1 行目に `function myFunction` がないことを確かめる。
   - メニューが出ないときは、Apps Script の上の関数の選択で `onOpen` を選び「▷ 実行」を押すと出ます。ノートパソコンで F5 が音量などのキーになっている場合は、アドレス欄の左の ↻ か Ctrl+R で再読み込みします。
4. 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、`appsscript.json` を `src/appsscript.json` の中身に置き換えて保存する。
5. スプレッドシートを再読み込みすると、メニューに「CSV 集計」が出る。

npm install -g @google/clasp

### 権限について
このツールは、設定したフォルダの CSV を読むために、ドライブのファイルを見る権限を求めます。Google の仕組みで、フォルダだけに絞ることはできません。ファイルを書き換える・消す・外に送るコードは入っていません（ソースの `main.js` で確かめられます）。外に送るための権限も求めていません。

| 権限（スコープ） | 使うところ |
|---|---|
| `spreadsheets.currentonly` | このスプレッドシートの「設定」を読み、出力のシートを書く |
| `drive.readonly` | 設定したフォルダのファイルの一覧と中身を読む |
| `script.container.ui` | メニューと、結果のメッセージ |

- 承認画面には、ドライブのファイルを見る権限として表示されます（画面の文はまだ確かめていません。「9. 動作確認」の手順で書き写して、ここに書きます）。
- 自分用のスクリプトなので、初回の承認で「このアプリは Google で確認されていません」と出ます。「詳細」→「（安全ではないページ）に移動」で進みます。
- 会社や学校の Google アカウント（Google Workspace）では、管理者の設定で、確認されていないアプリや `drive.readonly` のような権限の承認が止められていることがあります（仮説。まだ確かめていません）。承認の画面で先に進めないときは、管理者に相談するか、個人の Google アカウントで試してください。
- 承認を取り消すときは、Google アカウントの「セキュリティ」→「サードパーティのアプリとサービス」から、このスクリプトのアクセスを削除します（画面の名前と場所はまだ確かめていません）。

## 6. 実行方法
1. メニュー「CSV 集計」→「① 設定シートを作る」を実行する（初回は権限の承認が必要）。承認が終わったら、**もう一度同じメニューを押してください**（承認の直後は、押したメニューの処理が動かないことがあります。Google で未確認）。
   - どちらの処理も、スプレッドシートのメニューから実行してください。Apps Script エディターの「実行」ボタンから動かすと、処理は終わっても最後にメッセージを出すところで例外になります（Google で未確認）。
2. 「設定」シートの黄色いセルを確認する。

   | キー | 初期値 | 説明 |
   |---|---|---|
   | CSV_FOLDER | （空） | CSV を入れたドライブのフォルダの URL（ブラウザのアドレス欄をそのまま貼る）か、フォルダの ID |
   | ENCODING | 自動 | 自動 / UTF-8 / Shift_JIS。文字化けしたときだけ変える |
   | COL_DATE | 注文日 | 日付の列の見出し名 |
   | COL_PRODUCT | 商品名 | 商品の列の見出し名 |
   | COL_QUANTITY | 数量 | 数量の列の見出し名 |
   | COL_AMOUNT | 金額 | 金額の列の見出し名 |
   | COL_ORDER_ID | 注文番号 | 注文番号の列の見出し名。CSV にない場合は空にする（空にすると、別のファイルにある同じ内容の行は 1 行にまとめます。「9. 制限事項」） |
   | DEDUPE | TRUE | FALSE にすると重複を削除しない |
   | QUOTE_CHECK | TRUE | 引用符（`"`）で囲んだ複数行の値の中に、1 行分以上のデータに見える数のカンマがあればエラーにする。備考などに本当にカンマの多い複数行の文があってエラーになるときだけ FALSE にし、その回の集計が終わったら TRUE に戻す |
3. メニュー「② 集計する」を実行する。
4. 終わると、結果のメッセージが出ます。**メッセージの日時と、「取り込み結果」の表の下の「実行日時」（エラーのときは「エラー」シートの表の下の「実行日時」）が今の時刻になっているか見てください。** なっていなければ、今回の集計はできていません（何も表示されずに止まった場合も同じです。CSV を減らして実行し直してください）。
5. 「エラー」シートが出たときは、書かれたファイルと行を直してから、もう一度実行する。CSV はテキストエディターで直すか、出力元から出し直してください。

### 出力のシートについて
- 「集計」「月別合計」「明細」「取り込み結果」「エラー」の 5 シートは、実行のたびに消して作り直します。残したいものは、別のシートに値だけを貼り付けて残してください。
- 他のシートから `=集計!D2` のように直接参照すると、実行のたびに `#REF!` になるおそれがあります（2026-10-26 の Google での 1 回の記録では `#REF!` にならず、値が表示されました）。`INDIRECT("集計!D2")` や `QUERY` を使うか、別のスプレッドシートから `IMPORTRANGE` で読んでください。
- 「集計（作成中）」のように、上の 5 つの名前の最後に「（作成中）」が付いたシートは、中身を見ずに実行のたびに消えます。この名前を自分のシートに使わないでください。
- エラーがあったときは、前回の「集計」などのシートも消します（今回の結果と取り違えないため。元の CSV は変わらないので、直して実行すれば作り直せます）。
- 「設定」と、上の 5 つ以外のシートには書きません。5 つと同じ名前で 1 行目の見出しが違うシートがあると、何も書かずに止まります。そのシートの名前を変えてください。このツールのシートでも、表の右の列にメモなどを書くと止まります（消さないため）。メモは別のシートに移してください。

### 「読まなかったファイル」に名前が出たとき
- `memo.txt` のような `.csv` 以外のファイルや、`~$` で始まるファイルは、意図どおりなら気にしなくてかまいません。
- 「CSV が Google スプレッドシートに変わっている可能性があります」と出たファイルは、アップロードのときに Google スプレッドシートに変換されています。ドライブの「設定」（歯車）→「アップロードしたファイルを Google ドキュメント エディタ形式に変換する」をオフにしてから、CSV をアップロードし直してください。名前が `.csv` のまま変換されたファイルは「エラー」シートに出ます。
- フォルダに入れたショートカットは読めません。名前が `.csv` のショートカットは「ショートカットは読めません」のエラーになります。元の CSV をこのフォルダにコピーしてください。
- 名前の最後に空白が付いた `x.csv ` も読みません。名前を直してください。
- サブフォルダの中の CSV は読みません。同じフォルダに移してください。

### フォルダが見つからないとき
「フォルダが見つかりません」と出たら、CSV_FOLDER の URL と、そのフォルダを自分が開けるかを確かめてください。他の人から共有されたフォルダの場合は、持ち主に共有し直してもらうか、自分のドライブにコピーしてください。

## 7. 使用例
`excel-csv-aggregator/tests/cases/01-basic/input/` の 4 つの CSV（Shift_JIS・UTF-8 BOM あり・UTF-8 BOM なしの LF 改行と CRLF 改行。ダミーデータ）を集計すると、「月別合計」は次のようになります（期待値: `excel-csv-aggregator/tests/cases/01-basic/expected/monthly.csv`。VBA 版と同じ）。

| 年月 | 数量 | 金額 |
|---|---|---|
| 2026-08 | 6 | 8,660 |
| 2026-09 | 8 | 10,620 |
| 2026-10 | 1 | -380 |
| 合計 | 15 | 18,900 |

成功のメッセージは次のようになります（モックのテストで確かめた文。日時は実行した時刻）。
```
集計しました（2026-10-15 14:03:21）。CSV 4 件、明細 13 行（重複で除いた行 2）。「集計」「月別合計」「明細」「取り込み結果」シートを作り直しました。
読まなかったファイル: 2 件（memo.txt、~$a_2026-08.csv）
```

## 8. 制作時に工夫した点
- **集計のルールを VBA 版と 1 つにする**: VBA 版の参照実装 `lib.js` を 1 バイトも変えずにコピーし、ずれたらテストと CI で落ちるようにした。同じテストケース（期待値は手で計算したもの）を GAS 版でも流す。
- **黙って読み飛ばさない**: ドライブでは、アップロードの設定で CSV が Google スプレッドシートに変わり、名前から `.csv` が外れることがある。読まなかったファイルとサブフォルダの名前を毎回出し、名前が `.csv` のまま変換されたものはエラーにした。
- **文字化けしたまま集計しない**: Shift_JIS の変換で ①・㈱ が同じ置き換え文字になると、「ギフトセット ①」と「ギフトセット ②」が 1 つの商品にまとまってしまう。①・㈱ を持つ `windows-31j` を使い、それでも置き換え文字（U+FFFD）が出たファイルは行番号つきのエラーにした。
- **前回の結果を壊さない**: 「（作成中）」の名前で全部書いてから入れ替える。書いている途中で失敗したら作りかけを消し、前回の結果を残す。
- **数式として動かさない**: 商品名などの文字の列は、書式を書式なしテキストにしてから書き、`=`・`+`・`-`・`@` で始まる値には先頭に `'` を付ける（CSV インジェクション対策）。
- **権限を小さくする**: ドライブは読み取りだけ、スプレッドシートはこのファイルだけ。外部に送る権限は求めない（テストで権限の一覧とソースを確かめている）。
- **本物の困る動きをまねたテスト**: GAS のモックは、符号つきのバイト列、Java の Shift_JIS の表にない文字の置き換え、シートの範囲の外での例外などをまねる。

### 自己テスト（開発用。納品物には入れない）
**パソコンのブラウザ（Chrome など）で作業してください。** スマホのアプリではメニュー「CSV 集計」が出ない見込みです（未確認）。ドライブの「フォルダをアップロード」と Apps Script のエディターも、パソコンのブラウザで使います。

Google の上での動作確認を、メニューを押すだけで済むようにしたものです。テスト用のスプレッドシートで、共通テストケース 01〜06 を本番の処理に流し、結果を「自己テスト」シートに項目ごとの ○ / × / 未実施で書きます。2026-10-26 にオーナーの Google アカウントで動かし、判定 19 件がすべて ○ でした（下の「9. 制限事項と動作確認の状況」）。

- 「設定」シートは読まず、書きません。ドライブは読むだけです（ファイルを作る・消すコードはありません）。
- スプレッドシートの名前が「自己テスト」で始まらないと、何もせずに止まります（本番のデータを消さないため）。
- 全体の「すべて合格」は、**自動で確かめる項目だけ**が全部 ○ という意味です。本番のメニューからの実行（M01）と承認画面の文（M02）は含みません。

#### 注意

#### 確認状況の表の直し方（結果を受け取った人）
- **直す前に、I03 の `SJIS_CHARSET`・`FORMULA_GUARD` を見て、配布する `main.js` の値と同じときだけ直す**（たとえば `SJIS_CHARSET` を `'MS932'` に変えて合格した場合は、`windows-31j` の行を確認済みにしない）。
- ○ の項目に対応する行を「確認済み（日付、自己テスト C02、ケースは ZIP の日付）」に直す。× と未実施の行は直さない。
- **1 つの行に番号が複数あるときは、その全部が ○ のときだけ確認済みにする。** 1 つでも × か未実施なら直さない。
- **本番の入口を含む行**（「Google の環境での実行（共通テストケース 01〜06）」「承認画面の文、`drive.readonly` だけで動くか」）は、**自己テストの番号 ＋ M01（と M02）の両方がそろって初めて確認済み**にする。「M01 がそろう」は、M01 の E 列に書いた 5 つ（メニューの項目、出た文の 1 行目、「明細」の最後の行の番号、シートの並び、ZIP をダウンロードした日）が、どれも M01 の手順 7 の期待どおりであること。1 つでも違うか書いていなければ、そろっていない。片方だけなら「一部確認（自己テスト C01〜C19 は ○、本番のメニューは未確認）」と書く。
- `'` が見えるかは、C03 の ○ ではなく、C03 の詳細の LEN と見た目で直す（下の「数式の確認の結果の扱い」）。
- M03 は、この表のどの行にも結び付けない。任意の確認の行（2 つのタブで同時、Workspace の承認など）は、行ごとに「何を見て、どうだったか」をもらったときだけ確認済みにする。「全部 OK」のようなまとめた返事では直さない。

**数式の確認の結果の扱い**
- ISFORMULA が FALSE で LEN が 9（`'` が残らず、数式にもならない）: `FORMULA_GUARD` は `true` のまま。
- LEN が 10（`'` が文字として残る）: `FORMULA_GUARD` を `false` にして 01 を流し直し、同じ 2 つの式を見る。ISFORMULA が FALSE で LEN が 9 なら、書式なしテキストだけで防げているので、下の「数式の確認」の 5 つの値でも同じく防げるかを見てから `false` にする（`tests/cases.test.js` は `FORMULA_GUARD` を読んで期待値を作るので、そのまま通る）。1 つでも数式になったら `true` のまま（`'` が見えるのは許す）にし、この README に「先頭が `=`・`+`・`-`・`@` の商品名などは、先頭に `'` が付いて表示されます」と書く。どちらにしたかと理由を記録に残す。
- ISFORMULA が TRUE（数式になった）: 想定外。`'` も書式も効いていないので、**使うのを止めて director に知らせる**。

**変換の確認の結果の扱い**
- `'Shift_JIS'` で「エラー」シートに行 4 のエラーが出た: 想定どおり（GAS が Java の文字コード表を使い、表にない文字を U+FFFD にしている）。
- `'Shift_JIS'` でエラーにならず、① が `?` などの別の文字になった: 表にない文字が U+FFFD にならないので、文字化けの検査が効かない。
  - `'windows-31j'`（か `'MS932'`）で ①・㈱ が正しく出るなら、使ってよい。ただし壊れたファイル（途中で切れたものなど）の文字化けは検出できないことを、この README の確認状況に書く。
  - `'windows-31j'` も `'MS932'` も受け付けられず `'Shift_JIS'` に戻すしかなく、① が `?` などになる場合は、**使うのを止めて director に知らせる**（「ギフトセット ①」と「ギフトセット ②」が黙って 1 つの商品にまとまるため）。

### VBA 版との違い
- 入力はドライブのフォルダ、出力は同じスプレッドシートの 5 シート（毎回作り直し）。VBA 版は新しいブックを作る。
- 読まなかったファイル・サブフォルダの名前を出す（VBA 版は出さない）。
- 文字コードの変換で読めない文字があるとエラーになる。ENCODING を UTF-8 に固定して Shift_JIS のファイルを読んだときのエラーは、VBA 版の「見出しにありません」ではなく「文字コードの変換で読めない文字がありました」になる。
- 文字の列で `=`・`+`・`-`・`@` で始まる値の先頭に `'` を付ける（`FORMULA_GUARD`。動作確認の結果で変わることがある）。

### 制限事項
- 1 回の実行は 6 分までです（Google の上限）。CSV を読む前に 4 分、シートに書く前に 4 分 30 秒を過ぎていたら、何も書かずに止まります。扱える量の目安はまだ測っていません。フォルダを分けて 2 回に分けると、フォルダをまたぐ重複は除けません。
- 6 分の上限で強制的に止められたときは、メッセージが出ないことがあります。前回の結果は残り、「（作成中）」のシートは次の実行で消えます。
- 商品名の表記ゆれ（全角・半角、途中の空白の違い）は、別の商品として集計します。
- **同じ注文が Shift_JIS の CSV と UTF-8 の CSV の両方にあり、その値に `〜`・`−`・`‖`・`¢`・`£`・`¬`・`＼` が入っていると、文字コードによって別の文字になり、重複として除かれずに二重に数えます。** エラーにはならず、「取り込み結果」の「重複で除いた行」にも出ません。同じ期間の CSV は、出力元で文字コードをそろえて（すべて Shift_JIS か、すべて UTF-8 で）落としてください。
- 金額は CSV の値をそのまま足します（税計算や端数処理はしません）。
- サブフォルダの CSV、Google スプレッドシート形式のファイル、Excel ファイル、タブ区切りのファイルは読みません。
- **注文番号の列がない CSV では、同じ日・同じ商品・同じ数量・同じ金額の行が、別ファイルにあると 1 行にまとめられます。** 1 日分を複数のファイルに分けて出力している場合は、DEDUPE を FALSE にしてください。
- UTF-16 の CSV は読めません。UTF-8 か Shift_JIS で保存し直してください。
- 値の先頭に余分な `"` があって間の行が 1 つの値に入る形のうち、捕まえられない形があります（VBA 版と同じルールです。[VBA 版の README](../excel-csv-aggregator/README.md) の「9. 制限事項」と「行が消えていないかの確かめ方」を参照）。
- 元の CSV にもともと U+FFFD（�）の文字があると、文字化けとしてエラーになります。

## 開発
```bash
npm test          # lib.js の一致の確認 + 単体テスト + 結合テスト + 共通テストケース
npm run sync-lib  # excel-csv-aggregator/src/lib.js を src/lib.js にコピーする
```
- `src/lib.js` は手で編集しません。集計のルールを変えるときは `excel-csv-aggregator/src/lib.js`（と VBA のソース）を直してから `npm run sync-lib` を実行してください（テストと CI で一致を確かめています）。
- GAS では全ファイルが 1 つのグローバルの名前空間を共有します。`lib.js` の関数（`ParseCsv` など）は末尾に `_` がないので、Apps Script エディターの「実行する関数」の一覧に出ます。純粋関数なので、実行しても何も変わりません（内部用の関数名の末尾に `_` を付けるという決まりの例外）。
- シートのデザインルールは [docs/DESIGN.md](../docs/DESIGN.md) を参照。

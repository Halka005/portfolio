# 業務自動化ツール 作品集

Google スプレッドシート・Google Apps Script（GAS）と Excel VBA を使った、業務の「毎回の手作業」を減らすツールの作品集です。
すべて自主制作物で、テストと README をそろえ、同じ方針・同じルールで作っています。

プロフィールページ: https://halka005.github.io/portfolio/ （[docs/index.html](docs/index.html)）

## 作品
| 作品 | 内容 | 状態 |
|---|---|---|
| [問い合わせ・ヒアリング受付 自動化](gas-inquiry-automation/) | Google フォームの回答に受付番号をつけ、自動返信・担当者通知・対応状況の管理まで行う | テスト済み / **Google で主な流れを確認済み**（2026-10-26。実際のメール送信は未確認） |

CSV 集計は GAS 版を主な作品にしています。Excel VBA 版は、Excel で動かす環境がまだないため参考として置いています（集計ルールは GAS 版と共通で、Node.js の参照実装とテストケースで確認済み）。GAS 版のテストは、VBA 版のフォルダにあるテストケースを使います。

## 共通の作り方
- **安全を優先**: メールは最初「お試しモード」で動き、確認してから本番にする。送信前に人が確認できる形にする。元のファイル（CSV など）は読むだけで書き換えない。
- **再実行しても壊れない**: 処理済みの判定で、二重送信・二重発行をしない。
- **使う人が迷わない**: 入力してよいセルは薄い黄色に統一（[シートのデザインルール](docs/DESIGN.md)）。設定はコードではなくシートで変更できる。
- **テストで確認**: Google に依存しない処理は単体テスト、全体の流れは GAS をモック化した結合テストで確認する。VBA は CI で動かせないため、同じルールの参照実装（Node.js）と共通のテストケースで確かめる。
- **正直に書く**: 実際の環境で確認していないことは、README に「未確認」と書く。

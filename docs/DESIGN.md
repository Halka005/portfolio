# シートのデザインルール

依頼者が迷わず使えるように、どのツールでも同じ見た目のルールにする。

| 種類 | 背景色 | 意味 |
|---|---|---|
| 見出し | `#e0e0e0`（灰）・太字 | 触らない |
| 入力セル | `#fff8c5`（薄い黄色） | 依頼者が入力・変更してよい |
| 自動出力 | 白 | スクリプトが書き込む。手で編集しない |

- 見出し行は固定する（`setFrozenRows(1)`）。
- シート名は日本語で役割をそのまま書く（`設定`、`ログ`）。
- 設定シートは「キー / 値 / 説明」の 3 列。説明列に、何を入れるかを書く。
- ステータスなど選択肢がある列は、入力規則（プルダウン）にする。
- 列は位置ではなく見出し名で探す。列が増えたり並び替えられても壊れないようにする。
